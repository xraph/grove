## Installation

You need Go 1.25 or later (the Forge extension needs 1.26).

```bash
go get github.com/xraph/grove@latest
```

For PostgreSQL support (the most common driver):

```bash
go get github.com/xraph/grove/drivers/pgdriver@latest
```

Each driver is its own module, so you only download the client libraries for the databases you use. The [README quick start](https://github.com/xraph/grove#quick-start) has a runnable SQLite version of this page that needs no database server.

For use as a [Forge extension](/docs/integration/forge-extension):

```bash
go get github.com/xraph/grove/extension@latest
```

## Step 1: Define a Model

Grove uses struct tags to map Go types to database columns. Use `grove:"..."` tags for new models:

```go
package main

import (
    "time"

    "github.com/xraph/grove"
)

type User struct {
    grove.BaseModel `grove:"table:users,alias:u"`

    ID        int64     `grove:"id,pk,autoincrement"`
    Name      string    `grove:"name,notnull"`
    Email     string    `grove:"email,notnull,unique"`
    Role      string    `grove:"role,notnull,default:'user'"`
    CreatedAt time.Time `grove:"created_at,nullzero,notnull,default:current_timestamp"`
    DeletedAt *time.Time `grove:"deleted_at,soft_delete,nullzero"`
}
```

## Step 2: Connect to the Database

```go
import (
    "github.com/xraph/grove"
    "github.com/xraph/grove/driver"
    "github.com/xraph/grove/drivers/pgdriver"
)

// 1. Create and open the driver
pgdb := pgdriver.New()
if err := pgdb.Open(ctx, "postgres://user:pass@localhost:5432/mydb?sslmode=disable", driver.WithPoolSize(20)); err != nil {
    log.Fatal(err)
}

// 2. Pass the connected driver to Grove
db, err := grove.Open(pgdb)
if err != nil {
    log.Fatal(err)
}
defer db.Close()
```

## Step 3: Register Models

```go
db.RegisterModel((*User)(nil))
```

Registering caches the model's schema up front. Queries resolve unregistered models on first use too.

## Step 4: Query Data

Access the PostgreSQL-specific query builder with `Unwrap`. Write `?` placeholders and the driver numbers them `$1`, `$2` and so on:

```go
q := pgdriver.Unwrap(db)

// CREATE TABLE
_, err := q.NewCreateTable((*User)(nil)).IfNotExists().Exec(ctx)

// SELECT
var users []User
err = q.NewSelect(&users).
    Where("role = ?", "admin").
    OrderExpr("created_at DESC").
    Limit(10).
    Scan(ctx)

// INSERT
user := &User{Name: "Alice", Email: "alice@example.com"}
_, err = q.NewInsert(user).Exec(ctx)

// UPDATE
_, err = q.NewUpdate((*User)(nil)).
    Set("role = ?", "admin").
    Where("email = ?", "alice@example.com").
    Exec(ctx)

// DELETE (a soft delete, because the model has a soft_delete field)
_, err = q.NewDelete((*User)(nil)).
    Where("id = ?", userID).
    Exec(ctx)
```

## Step 5: Use Existing Bun Models

If you're migrating from bun, your existing models load unchanged, because Grove falls back to `bun:"..."` tags when a field has no `grove:"..."` tag:

```go
// Existing bun model, works as-is
type LegacyUser struct {
    grove.BaseModel `bun:"table:users,alias:u"`

    ID    int64  `bun:"id,pk,autoincrement"`
    Name  string `bun:"name,notnull"`
    Email string `bun:"email,notnull,unique"`
}
```
