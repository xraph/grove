import { Callout } from 'fumadocs-ui/components/callout';

The `github.com/xraph/grove/extension` module plugs Grove into a [Forge](https://github.com/xraph/forge) app. It opens the database during `Register`, provides `*grove.DB` through Forge's DI container, adds your hooks and migration groups, reports health, and closes the connection on shutdown. It's a separate module and needs Go 1.26, the same as Forge.

## Installation

```bash
go get github.com/xraph/grove/extension@latest
go get github.com/xraph/grove/drivers/pgdriver@latest
```

## Quick Start

```go
import (
    "net/http"

    "github.com/xraph/forge"
    "github.com/xraph/grove"
    "github.com/xraph/grove/drivers/pgdriver"
    _ "github.com/xraph/grove/drivers/pgdriver/pgmigrate"
    groveext "github.com/xraph/grove/extension"
    "github.com/xraph/grove/hook"
)

app := forge.NewApp(forge.AppConfig{
    Name:        "accounts",
    HTTPAddress: ":8080",
    Extensions: []forge.Extension{
        groveext.New(
            groveext.WithDSN("postgres", "postgres://localhost:5432/accounts?sslmode=disable"),
            groveext.WithMigrations(Migrations),
            groveext.WithHook(TenantScope{}, hook.Scope{Tables: []string{"orders"}}),
        ),
    },
})

err := app.Router().GET("/users/count", func(ctx forge.Context) error {
    db, err := forge.Inject[*grove.DB](app.Container())
    if err != nil {
        return err
    }

    n, err := pgdriver.Unwrap(db).NewSelect((*User)(nil)).Count(ctx.Context())
    if err != nil {
        return err
    }

    return ctx.JSON(http.StatusOK, map[string]int64{"users": n})
})
```

The extension doesn't import any driver itself. Import the driver you use (by name, or blank), plus its `<name>migrate` package if you have migrations. Without the driver import, `WithDSN` fails with an unknown-driver error; without the migrate import, migrations fail with no executor.

`WithDriver(drv)` takes a driver you've already opened instead of a DSN.

### YAML Configuration

```yaml
extensions:
  grove:
    driver: postgres
    dsn: "postgres://user:pass@localhost:5432/mydb?sslmode=disable"
```

```go
app := forge.New(
    forge.WithAppName("accounts"),
    forge.WithExtensions(groveext.New()), // config loaded from YAML
)
```

The extension reads `extensions.grove`, then falls back to a top-level `grove` key. YAML wins for `driver` and `dsn`, and options you pass in code fill whatever YAML leaves empty.

## Configuration Reference

| Field | YAML Key | Type | Description |
|-------|----------|------|-------------|
| Driver | `driver` | `string` | Driver name as registered: `postgres` or `pg`, `mysql`, `sqlite`, `turso`, `mongodb` or `mongo`, `clickhouse`, `elasticsearch` |
| DSN | `dsn` | `string` | Connection string |
| Databases | `databases` | `[]DatabaseConfig` | Named databases (`name`, `driver`, `dsn`) for multi-DB mode |
| Default | `default` | `string` | Default database name in multi-DB mode |
| DisableMigrate | `disable_migrate` | `bool` | Makes `Migrate` and `Rollback` return an error |
| LockTimeout | `lock_timeout` | `duration` | How long migrations wait for the lock. `0` uses the migrate default, negative waits for the context deadline |
| CentralMigrations | `central_migrations` | `bool` | Hand the migration groups to a shared registry that runs every extension's migrations in one ordered pass |
| DisableRoutes | `disable_routes` | `bool` | Skip the CRDT sync routes |
| BasePath | `base_path` | `string` | Prefix for the CRDT sync routes (default `/sync`) |

## Options

### Single-DB Options

```go
groveext.New(
    // An opened driver (takes precedence over YAML).
    groveext.WithDriver(pgdb),

    // Or a driver name and DSN, resolved through the driver registry.
    groveext.WithDSN("postgres", "postgres://user:pass@localhost:5432/mydb?sslmode=disable"),

    // Migration groups.
    groveext.WithMigrations(billing.Migrations, notifications.Migrations),

    // Hooks, with an optional scope.
    groveext.WithHook(&tenantHook, hook.Scope{Tables: []string{"orders"}}),

    // Behavior flags.
    groveext.WithDisableMigrate(),
    groveext.WithDisableRoutes(),
    groveext.WithBasePath("/api/sync"),
    groveext.WithLockTimeout(30 * time.Second),
    groveext.WithCentralMigrations(),

    // Fail Register when there's no YAML config.
    groveext.WithRequireConfig(true),

    // CRDT integration (see below).
    groveext.WithCRDT(crdtPlugin),
    groveext.WithSyncer(syncer),
    groveext.WithSyncController(crdt.WithStreamPollInterval(2 * time.Second)),
)
```

`WithDriverFactory(name, factory)` overrides how the extension builds the driver for one driver name.

### Multi-DB Options

```go
groveext.New(
    // Named databases with opened drivers.
    groveext.WithDatabase("primary", pgdb),
    groveext.WithDatabase("analytics", chdb),

    // Or named databases from a driver name and DSN.
    groveext.WithDatabaseDSN("cache", "sqlite", "file:cache.db"),

    // The default database (returned by DB() and unnamed DI).
    groveext.WithDefaultDatabase("primary"),

    // Per-database hooks and migrations.
    groveext.WithHookFor("primary", &tenantHook, hook.Scope{Tables: []string{"orders"}}),
    groveext.WithMigrationsFor("primary", core.Migrations, billing.Migrations),
    groveext.WithMigrationsFor("analytics", analytics.Migrations),

    // Global hooks run on every database.
    groveext.WithHook(&auditHook),

    // CRDT on a specific database.
    groveext.WithCRDT(crdtPlugin),
    groveext.WithCRDTDatabase("primary"),
)
```

## Lifecycle

### Register

1. Calls `BaseExtension.Register()` to store the app, logger and metrics.
2. Loads configuration: YAML (`extensions.grove`, then `grove`), merged with your options and the defaults.
3. Picks single-DB or multi-DB mode.
4. Opens the database(s) and adds the hooks.
5. Provides the databases through DI.
6. Mounts the CRDT sync routes if `WithCRDT` is set and routes aren't disabled.

### Start

Starts the CRDT background syncer if you passed `WithSyncer`, then marks the extension started.

### Stop

Closes the database in single-DB mode, or every database through the `DBManager` in multi-DB mode.

### Health

Single-DB mode returns an error until the database is open. Multi-DB mode returns an error if any registered database is nil. Neither pings the database.

## Accessing the DB

```go
db, err := forge.Inject[*grove.DB](app.Container())
if err != nil {
    return err
}

var users []User
err = pgdriver.Unwrap(db).NewSelect(&users).
    Where("active = ?", true).
    OrderExpr("created_at DESC").
    Limit(10).
    Scan(ctx)
```

You can also keep the `*extension.Extension` and call `ext.DB()` once it has registered.

## Multi-Database Support

### YAML Configuration

```yaml
extensions:
  grove:
    databases:
      - name: primary
        driver: postgres
        dsn: "postgres://user:pass@localhost:5432/app?sslmode=disable"
      - name: analytics
        driver: clickhouse
        dsn: "clickhouse://localhost:9000/analytics"
      - name: cache
        driver: sqlite
        dsn: "file:cache.db"
    default: primary
```

### Accessing Named Databases

```go
import (
    "github.com/xraph/forge"
    "github.com/xraph/grove"
    groveext "github.com/xraph/grove/extension"
    "github.com/xraph/vessel"
)

// The default database (unnamed injection).
defaultDB, err := forge.Inject[*grove.DB](app.Container())

// A specific named database.
analyticsDB, err := vessel.InjectNamed[*grove.DB](app.Container(), "analytics")

// The DBManager, for access by name at runtime.
mgr, err := forge.Inject[*groveext.DBManager](app.Container())
cacheDB, err := mgr.Get("cache")
```

### DI Registration

| Service | Resolution | Description |
|---------|-----------|-------------|
| `*grove.DB` | `forge.Inject[*grove.DB](c)` | The default database |
| `*grove.DB` (named) | `vessel.InjectNamed[*grove.DB](c, "name")` | A named database (multi-DB mode) |
| `*extension.DBManager` | `forge.Inject[*extension.DBManager](c)` | The manager (multi-DB mode) |

### DBManager API

```go
mgr := ext.Manager() // nil in single-DB mode

db, err := mgr.Get("analytics")
db, err := mgr.Default()
name := mgr.DefaultName()
err := mgr.SetDefault("analytics")
all := mgr.All() // a copy
n := mgr.Len()
err := mgr.Close()
```

### CRDT with Multi-DB

```go
groveext.New(
    groveext.WithDatabase("primary", pgdb),
    groveext.WithDatabase("analytics", chdb),

    groveext.WithCRDT(crdtPlugin, hook.Scope{Tables: []string{"documents"}}),
    groveext.WithCRDTDatabase("primary"), // CRDT hooks on primary only
    groveext.WithSyncer(syncer),
)
```

Without `WithCRDTDatabase`, the CRDT hook goes on the default database.

## Driver Registry

Importing a driver package registers it by name, which is what the YAML path and `WithDSN` use:

```go
import _ "github.com/xraph/grove/drivers/pgdriver"

drv, err := grove.OpenDriver(ctx, "postgres", "postgres://user:pass@localhost:5432/mydb?sslmode=disable")
db, err := grove.Open(drv)
```

To register your own driver, call `grove.RegisterDriver(name, factory)`, where the factory is a `grove.DriverFactory`.

## CRDT Integration

```go
import (
    "github.com/xraph/grove/crdt"
    groveext "github.com/xraph/grove/extension"
    "github.com/xraph/grove/hook"
)

plugin := crdt.New(
    crdt.WithNodeID("node-1"),
    crdt.WithTables("documents", "comments"),
)
plugin.SetExecutor(crdtExecutor{drv: pgdb}) // see the note below

syncer := crdt.NewSyncer(plugin,
    crdt.WithPeers(
        crdt.HTTPTransport("http://node-2:8080/sync"),
        crdt.HTTPTransport("http://node-3:8080/sync"),
    ),
    crdt.WithSyncTables("documents", "comments"),
)

ext := groveext.New(
    groveext.WithDriver(pgdb),
    groveext.WithCRDT(plugin, hook.Scope{Tables: []string{"documents", "comments"}}),
    groveext.WithSyncer(syncer),
    groveext.WithSyncController(
        crdt.WithStreamPollInterval(2 * time.Second),
        crdt.WithStreamKeepAlive(30 * time.Second),
    ),
)
```

<Callout type="warn">
The extension doesn't give the CRDT plugin a database executor. Call `plugin.SetExecutor(...)` (and `plugin.EnsureShadowTable` for each table) before the app registers the extension. Without an executor, mutations record no CRDT state and the sync controller has no metadata store to serve from. [CRDT Getting Started](/docs/crdt/getting-started) has a small adapter from a Grove driver to `crdt.Executor`.
</Callout>

Under the base path (`/sync` by default) the extension mounts:

| Method | Path | When |
|--------|------|------|
| POST | `/sync/pull` | Always |
| POST | `/sync/push` | Always |
| GET | `/sync/stream` | Always (SSE) |
| GET | `/sync/ws` | Always (WebSocket) |
| POST, GET | `/sync/presence` | With `crdt.WithPresenceEnabled(true)` |
| GET, POST | `/sync/history`, GET `/sync/field-history` | With `crdt.WithTimeTravelEnabled(true)` |
| various | `/sync/rooms/...` | With `crdt.WithRoomManager(true)` |

Use `WithBasePath()` to change the prefix, or `WithDisableRoutes()` to mount nothing.

## CLI Migration Commands

The extension implements `forge.MigratableExtension`, but a plain `app.Run()` doesn't apply migrations. Run your app through Forge's CLI runner to get migration commands:

```go
package main

import (
    "github.com/xraph/forge"
    "github.com/xraph/forge/cli"

    _ "github.com/xraph/grove/drivers/pgdriver"
    _ "github.com/xraph/grove/drivers/pgdriver/pgmigrate" // register the pg executor
    groveext "github.com/xraph/grove/extension"

    "myapp/migrations/core"
)

func main() {
    cli.NewAppRunner(func(ctx cli.CommandContext) (forge.App, error) {
        return forge.New(
            forge.WithAppName("myapp"),
            forge.WithExtensions(groveext.New(
                groveext.WithDSN("postgres", "postgres://localhost:5432/myapp?sslmode=disable"),
                groveext.WithMigrations(core.Migrations),
            )),
        ), nil
    }).AutoMigrate().Run()
}
```

`cli.RunApp(setup, cli.WithAutoMigrate())` does the same thing in one call.

### Available Commands

| Command | Description |
|---------|-------------|
| `myapp migrate up` | Run all pending migrations |
| `myapp migrate down` | Roll back the last migration batch |
| `myapp migrate status` | Show applied and pending migrations per group |

`AutoMigrate()` applies pending migrations before the server starts.

### Executor Registration

Import the migrate package for your driver so `migrate.NewExecutorFor` can find the executor:

```go
import _ "github.com/xraph/grove/drivers/pgdriver/pgmigrate"         // PostgreSQL
import _ "github.com/xraph/grove/drivers/mysqldriver/mysqlmigrate"   // MySQL
import _ "github.com/xraph/grove/drivers/sqlitedriver/sqlitemigrate" // SQLite
```

<Callout type="warn">
If you see `no executor registered for driver "pg"`, you're missing the driver's migrate package import.
</Callout>

## KV Store Integration

The KV module has its own Forge extension, `github.com/xraph/grove/kv/extension`, configured under `extensions.grove_kv`:

```go
import (
    _ "github.com/xraph/grove/kv/drivers/redisdriver"
    kvext "github.com/xraph/grove/kv/extension"
)

app := forge.New(
    forge.WithAppName("accounts"),
    forge.WithExtensions(kvext.New(
        kvext.WithDSN("redis", "redis://localhost:6379/0"),
    )),
)
```

It provides `*kv.Store` through DI, with `WithStore` and `WithStoreDSN` for named stores. See the [KV overview](/docs/kv/overview).

## Standalone Usage

`Init` opens the database and adds hooks without Forge. It needs a driver from `WithDriver`:

```go
ext := groveext.New(
    groveext.WithDriver(pgdb),
    groveext.WithHook(&auditHook),
)

if err := ext.Init(nil); err != nil {
    log.Fatal(err)
}

db := ext.DB()
defer db.Close()
```
