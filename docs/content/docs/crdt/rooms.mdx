Rooms extend the [Presence & Awareness](/docs/crdt/presence) system with structured collaborative spaces. Presence tracks who is here; rooms answer who is working on what, with participant limits, cursor tracking, typing indicators and lifecycle hooks.

## Overview

A room is a named collaborative space scoped to a document, a canvas or any other context. Rooms give you:

- Participant limits to control concurrency (say, at most 5 editors)
- Cursor tracking for canvas, text and code editors
- Typing indicators per participant
- Metadata per room and per participant
- Lifecycle hooks for logging and side effects
- Document room helpers that tie a room to a table record

Rooms sit on top of presence and use its TTL cleanup and SSE broadcast. A room's ID is also its presence topic.

## Server Setup (Go)

### Forge Integration

Rooms need presence and their own option:

```go
app.RegisterExtension(groveext.New(
    groveext.WithDriver(pgdb),
    groveext.WithCRDT(plugin, hook.Scope{Tables: []string{"documents"}}),
    groveext.WithSyncController(
        crdt.WithPresenceEnabled(true),
        crdt.WithPresenceTTL(30 * time.Second),
        crdt.WithRoomManager(true),
    ),
))
```

With both on, the extension mounts the room routes under `<base_path>/rooms`.

### Standalone Server

```go
ctrl := crdt.NewSyncController(plugin,
    crdt.WithPresenceEnabled(true),
    crdt.WithPresenceTTL(30 * time.Second),
    crdt.WithRoomManager(true),
)
defer ctrl.Close()

// RoomHTTPHandler serves /rooms, /rooms/{id} and the rest under whatever prefix you mount.
http.Handle("/sync/", http.StripPrefix("/sync", crdt.RoomHTTPHandler(ctrl.Rooms())))
```

## RoomManager

The `RoomManager` creates rooms, handles join and leave, and tracks participants. Get it from the controller; it's `nil` unless both presence and rooms are enabled:

```go
rm := ctrl.Rooms()
```

### Creating Rooms

```go
room, err := rm.CreateRoom(ctx, "design-review", "canvas",
    crdt.WithMaxParticipants(10),
    crdt.WithRoomMetadata(map[string]any{"project": "grove", "team": "platform"}),
    crdt.WithRoomCreator("node-1"),
)
```

### Room Options

| Option | Description |
|--------|-------------|
| `WithMaxParticipants(n)` | Maximum number of participants (0 means unlimited) |
| `WithRoomMetadata(v)` | Room metadata, stored as JSON |
| `WithRoomType(t)` | Room type (for `CreateDocumentRoom`, which takes no type argument) |
| `WithRoomCreator(nodeID)` | The node that created the room |

### Joining and Leaving

```go
data, _ := json.Marshal(map[string]any{
    "name":   "Alice",
    "color":  "#3b82f6",
    "cursor": map[string]any{"x": 120, "y": 340},
})
err := rm.JoinRoom(ctx, "design-review", "node-1", data)

rm.LeaveRoom(ctx, "design-review", "node-1")
rm.LeaveAllRooms(ctx, "node-1")
```

`JoinRoom` returns an error when the room is full. A room whose last participant leaves is removed.

### Listing and Inspecting

```go
all := rm.ListRooms()                // []RoomInfo
canvases := rm.ListRoomsByType("canvas")
room := rm.GetRoom("design-review")  // *Room, or nil
info := rm.GetRoomInfo("design-review") // *RoomInfo with participants
n := rm.ParticipantCount("design-review")
err := rm.SetRoomMetadata("design-review", map[string]any{"title": "Q3 review"})
```

## Cursor Tracking

`CursorPosition` covers canvas, text and code editors in one type. Set the fields that apply:

```go
type CursorPosition struct {
    X, Y           float64 // canvas
    Offset         int     // text: character offset
    Line, Column   int     // code: line and column
    SelectionStart int
    SelectionEnd   int
    Field          string  // which field or element the cursor is in
}
```

```go
rm.UpdateCursor("design-review", "node-1", crdt.CursorPosition{X: 450.5, Y: 230})
rm.UpdateCursor("doc-room", "node-1", crdt.CursorPosition{Line: 42, Column: 18})
rm.UpdateTypingStatus("doc-room", "node-1", true)
```

## Document Room Helpers

These tie a room to a record. The room ID comes from `crdt.DocumentRoomID(table, pk)`:

```go
room, err := rm.CreateDocumentRoom(ctx, "documents", "doc-1", crdt.WithMaxParticipants(5))

err = rm.JoinDocumentRoom(ctx, "documents", "doc-1", "node-1", data)

participants := rm.GetDocumentParticipants("documents", "doc-1")

rm.LeaveDocumentRoom(ctx, "documents", "doc-1", "node-1")
```

## Room Lifecycle Hooks

Implement `RoomHook` and add it to the manager:

```go
type RoomHook interface {
    OnRoomCreated(ctx context.Context, room *Room) error
    OnRoomDestroyed(ctx context.Context, room *Room) error
    OnParticipantJoin(ctx context.Context, room *Room, nodeID string) error
    OnParticipantLeave(ctx context.Context, room *Room, nodeID string) error
}
```

```go
type roomLogger struct{}

func (roomLogger) OnRoomCreated(ctx context.Context, room *crdt.Room) error {
    log.Printf("room %s created (max %d)", room.ID, room.MaxParticipants)
    return nil
}
func (roomLogger) OnRoomDestroyed(ctx context.Context, room *crdt.Room) error { return nil }
func (roomLogger) OnParticipantJoin(ctx context.Context, room *crdt.Room, nodeID string) error {
    log.Printf("%s joined %s", nodeID, room.ID)
    return nil
}
func (roomLogger) OnParticipantLeave(ctx context.Context, room *crdt.Room, nodeID string) error {
    return nil
}

rm.AddHook(roomLogger{})
```

For authorization before a join, use the controller's plugin chain. See [Plugins](/docs/crdt/plugins).

## HTTP API Reference

Paths are under the sync base path (`/sync` by default):

| Method | Path | Description |
|--------|------|-------------|
| GET | `/sync/rooms` | List rooms (optional `type` query parameter) |
| POST | `/sync/rooms` | Create a room |
| GET | `/sync/rooms/:id` | Room details and participants |
| POST | `/sync/rooms/:id/join` | Join a room |
| POST | `/sync/rooms/:id/leave` | Leave a room |
| GET | `/sync/rooms/:id/participants` | Current participants |
| POST | `/sync/rooms/:id/cursor` | Update a cursor |
| POST | `/sync/rooms/:id/typing` | Update typing status |
| PUT | `/sync/rooms/:id/metadata` | Replace room metadata |

### Create Room

**`POST /sync/rooms`**

```json
{
  "id": "design-review",
  "type": "canvas",
  "max_participants": 10,
  "metadata": { "project": "grove" },
  "created_by": "browser-1"
}
```

### Join Room

**`POST /sync/rooms/:id/join`**

```json
{
  "node_id": "browser-1",
  "data": { "name": "Alice", "color": "#3b82f6", "cursor": { "x": 0, "y": 0 } }
}
```

### Update Cursor

**`POST /sync/rooms/:id/cursor`**

```json
{ "node_id": "browser-1", "cursor": { "x": 200, "y": 150 } }
```

### Update Typing

**`POST /sync/rooms/:id/typing`**

```json
{ "node_id": "browser-1", "is_typing": true }
```

## TypeScript Client

### RoomClient

```typescript
import { RoomClient, randomColor } from "@grove-js/crdt";

const rooms = new RoomClient({
    baseURL: "/api/sync",
    headers: { Authorization: "Bearer <token>" },
});

await rooms.createRoom("design-session", { type: "canvas", max_participants: 10 });
await rooms.joinRoom("design-session", "browser-1", {
    name: "Alice",
    color: randomColor(),
    cursor: { x: 0, y: 0 },
});

// Update the cursor on mouse move.
await rooms.updateCursor("design-session", "browser-1", { x: 200, y: 150 });
await rooms.updateTyping("design-session", "browser-1", true);

// List rooms.
const allRooms = await rooms.listRooms();

// Leave on cleanup.
await rooms.leaveRoom("design-session", "browser-1");
```

`joinDocumentRoom(table, pk, nodeId, data)` and `leaveDocumentRoom` do the same for a record's room.

### React Hooks

#### useRoom

`useRoom` joins on mount and leaves on unmount:

```tsx
import { useRoom } from "@grove-js/crdt/react";

function CollabCanvas({ roomId }: { roomId: string }) {
    const { others, updateCursor } = useRoom(roomId, {
        nodeId: "browser-1",
        name: "Alice",
        color: "#3b82f6",
    });

    const handleMouseMove = (e: React.MouseEvent) => {
        updateCursor({ x: e.clientX, y: e.clientY });
    };

    return (
        <div onMouseMove={handleMouseMove}>
            {others.map((p) => (
                <Cursor key={p.node_id} data={p.data} />
            ))}
        </div>
    );
}
```

It returns `others`, `self`, `count`, `updateCursor`, `setTyping`, `updatePresence`, `leave` and `room`.

#### useDocumentRoom

```tsx
import { useDocumentRoom } from "@grove-js/crdt/react";

function DocumentEditor({ docId }: { docId: string }) {
    const { others } = useDocumentRoom("documents", docId, {
        nodeId: "browser-1",
        name: "Alice",
        color: "#3b82f6",
    });

    return (
        <div className="active-editors">
            {others.map((p) => (
                <span key={p.node_id} style={{ color: p.data.color }}>
                    {p.data.name}
                    {p.data.is_typing && " (typing...)"}
                </span>
            ))}
        </div>
    );
}
```

#### useRoomList

```tsx
import { useRoomList } from "@grove-js/crdt/react";

function RoomBrowser() {
    const { rooms, loading, refresh } = useRoomList();

    if (loading) return <div>Loading rooms...</div>;

    return (
        <ul>
            {rooms.map((room) => (
                <li key={room.id}>
                    {room.id}: {room.participant_count}/{room.max_participants ?? "unlimited"} participants
                </li>
            ))}
            <button onClick={refresh}>Refresh</button>
        </ul>
    );
}
```

## Example: Collaborative Document Editor with Cursors

```tsx
import { CRDTProvider, useDocument, useDocumentRoom } from "@grove-js/crdt/react";

function App() {
    return (
        <CRDTProvider config={{
            baseURL: "/api/sync",
            nodeID: `browser-${crypto.randomUUID()}`,
            tables: ["documents"],
        }}>
            <CollaborativeEditor docId="doc-1" />
        </CRDTProvider>
    );
}

function CollaborativeEditor({ docId }: { docId: string }) {
    const { data, update } = useDocument("documents", docId);
    const { others, setTyping, updateCursor } = useDocumentRoom("documents", docId, {
        nodeId: "browser-1",
        name: "Alice",
        color: "#3b82f6",
    });

    return (
        <div>
            <div className="collaborators">
                {others.map((p) => (
                    <span key={p.node_id} style={{ backgroundColor: p.data.color }}>
                        {p.data.name}
                        {p.data.is_typing && " ..."}
                    </span>
                ))}
            </div>
            <textarea
                value={data?.body ?? ""}
                onChange={(e) => update("body", e.target.value)}
                onKeyDown={() => setTyping(true)}
                onBlur={() => setTyping(false)}
                onSelect={(e) => updateCursor({ offset: e.currentTarget.selectionStart })}
            />
        </div>
    );
}
```
