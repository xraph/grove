Grove CRDT includes an optional time-travel system that records field-level history. When enabled, you can query the state of any record at any point in time, view the change history of individual fields, and build audit trails for compliance or debugging.

## Overview

Time-travel is **opt-in** and disabled by default to avoid storage overhead. When enabled, the CRDT layer records every field-level change with its HLC timestamp, enabling:

- **State-at-time queries** to read what a record looked like at any past moment
- **Field history** to see every change to a specific field with timestamps and node IDs
- **Audit trails** for compliance, debugging, and accountability
- **Field-level undo** by reverting to a previous field value
- **Debugging** concurrent merge issues by inspecting the full change timeline

## Server Setup (Go)

### Enabling Time-Travel

Enable time-travel on the `SyncController`:

```go
app.RegisterExtension(groveext.New(
    groveext.WithDriver(pgdb),
    groveext.WithCRDT(plugin, hook.Scope{Tables: []string{"documents"}}),
    groveext.WithSyncController(
        crdt.WithTimeTravelEnabled(true),
    ),
))
```

### Standalone Server

```go
handler := crdt.NewHTTPHandler(plugin,
    crdt.WithTimeTravelEnabled(true),
)
http.Handle("/sync/", http.StripPrefix("/sync", handler))
```

When time travel is enabled, the Forge extension mounts the history endpoints next to the sync routes.

## Querying State at a Point in Time

The history reads live on the plugin's metadata store (set with `SetExecutor`):

```go
ms := plugin.MetadataStore()

// Read the state of a document as of a specific HLC.
state, err := ms.ReadStateAt(ctx, "documents", "doc-1", targetHLC)
if err != nil {
    log.Fatal(err)
}

// state holds the merged CRDT state as of targetHLC.
// Fields that didn't exist at that time are absent.
if fs := state.Fields["title"]; fs != nil {
    fmt.Println("Title at that time:", string(fs.Value))
}
```

Through the controller, `ctrl.HandleHistory(ctx, &crdt.HistoryRequest{Table: "documents", PK: "doc-1", AtHLC: targetHLC})` does the same and runs any `TimeTravelInterceptor` plugins.

### Using wall-clock time

An `HLC` is a physical timestamp in nanoseconds plus a logical counter and a node ID, so you can build one from a `time.Time`:

```go
targetTime := time.Date(2025, 6, 15, 14, 30, 0, 0, time.UTC)
targetHLC := crdt.HLC{Timestamp: targetTime.UnixNano()}

state, err := ms.ReadStateAt(ctx, "documents", "doc-1", targetHLC)
```

## Querying Field History

```go
// Up to 50 versions of the "title" field, newest first. A zero HLC means "from the beginning".
history, err := ms.ReadFieldHistory(ctx, "documents", "doc-1", "title", crdt.HLC{}, 50)
if err != nil {
    log.Fatal(err)
}

for _, entry := range history {
    fmt.Printf("  %s: %s (by node %s)\n",
        time.Unix(0, entry.HLC.Timestamp).Format(time.RFC3339),
        entry.Value,
        entry.NodeID,
    )
}
```

A limit of 0 or less means 100. `ctrl.HandleFieldHistory` takes a `FieldHistoryRequest` with the same fields.

### FieldHistoryEntry

```go
type FieldHistoryEntry struct {
    HLC    HLC             `json:"hlc"`
    NodeID string          `json:"node_id"`
    Value  json.RawMessage `json:"value,omitempty"`
    Type   CRDTType        `json:"type"`
}
```

## HTTP API

When time travel is enabled, these endpoints are registered under the sync base path:

| Method | Path | Description |
|--------|------|-------------|
| GET, POST | `/sync/history` | Record state at a point in time |
| GET, POST | `/sync/field-history` | Change history for one field |

### Get State at Time

**`GET /sync/history?table=documents&pk=doc-1&at_ts=1706000000000000000&at_c=0&at_node=node-1`**

`at_ts` is the HLC timestamp in nanoseconds, `at_c` the counter and `at_node` the node ID. Leave them out for the current state. A POST takes the same thing as a `HistoryRequest` body (`table`, `pk`, `at_hlc`).

```json
{
  "table": "documents",
  "pk": "doc-1",
  "at_hlc": { "ts": 1706000000000000000, "c": 0, "node": "node-1" },
  "state": {
    "table": "documents",
    "pk": "doc-1",
    "fields": {
      "title": {
        "type": "lww",
        "hlc": { "ts": 1705999000000000000, "c": 0, "node": "node-1" },
        "node_id": "node-1",
        "value": "Draft Title"
      }
    }
  }
}
```

### Get Field History

**`GET /sync/field-history?table=documents&pk=doc-1&field=title&limit=50`**

```json
{
  "table": "documents",
  "pk": "doc-1",
  "field": "title",
  "entries": [
    {
      "hlc": { "ts": 1706000000000000000, "c": 0, "node": "node-1" },
      "node_id": "node-1",
      "value": "Final Title",
      "type": "lww"
    },
    {
      "hlc": { "ts": 1705999000000000000, "c": 0, "node": "node-2" },
      "node_id": "node-2",
      "value": "Draft v2",
      "type": "lww"
    }
  ]
}
```

Entries come back newest first.

## Use Cases

### Audit Trail

Track who changed what and when for compliance:

```go
history, _ := ms.ReadFieldHistory(ctx, "contracts", "contract-1", "status", crdt.HLC{}, 100)
for _, entry := range history {
    log.Printf("Status changed to %s by %s at %s",
        entry.Value, entry.NodeID, time.Unix(0, entry.HLC.Timestamp))
}
```

### Field-Level Undo

Revert a field to its previous value:

```go
history, _ := ms.ReadFieldHistory(ctx, "documents", "doc-1", "title", crdt.HLC{}, 2)
if len(history) >= 2 {
    var previous string
    _ = json.Unmarshal(history[1].Value, &previous) // second entry is the previous value

    // Write it back as a new change through your normal update path.
    _, err := pgdriver.Unwrap(db).NewUpdate((*Document)(nil)).
        Set("title = ?", previous).
        Where("id = ?", "doc-1").
        Exec(ctx)
}
```

### Debugging Merge Issues

Inspect the full timeline of changes to understand how a merge resolved:

```go
history, _ := ms.ReadFieldHistory(ctx, "documents", "doc-1", "title", crdt.HLC{}, 100)
for _, entry := range history {
    fmt.Printf("  [%s] node=%s value=%s\n",
        entry.HLC, entry.NodeID, entry.Value)
}
// Output shows the full sequence of writes from all nodes,
// making it clear which write won and why.
```

### Diffing Two Points in Time

Compare the state of a record at two different times:

```go
stateA, _ := ms.ReadStateAt(ctx, "documents", "doc-1", hlcA)
stateB, _ := ms.ReadStateAt(ctx, "documents", "doc-1", hlcB)

for field, fsB := range stateB.Fields {
    fsA := stateA.Fields[field]
    if fsA == nil {
        fmt.Printf("Field %s added: %s\n", field, fsB.Value)
    } else if string(fsA.Value) != string(fsB.Value) {
        fmt.Printf("Field %s changed: %s -> %s\n", field, fsA.Value, fsB.Value)
    }
}
```

## Plugin Integration

History reads through the controller can be intercepted with a [plugin](/docs/crdt/plugins) that implements `TimeTravelInterceptor`:

```go
type TimeTravelInterceptor interface {
    BeforeHistoryRead(ctx context.Context, table, pk string, atHLC HLC) error
    AfterHistoryRead(ctx context.Context, table, pk string, state *State) (*State, error)
}
```

Use it for access control on history, redaction or logging. Reads made directly on the `MetadataStore` skip it.

## Performance Considerations

- **Storage**: Time-travel records every field change. For high-write tables, this can grow quickly. Consider enabling it only on tables where history is valuable.
- **Queries**: State-at-time queries scan field history up to the target HLC. For records with many changes, this may be slower than reading current state.
- **Cleanup**: Consider implementing periodic cleanup of old history entries for tables where only recent history matters.
