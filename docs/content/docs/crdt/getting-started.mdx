This guide walks through the complete setup for Grove CRDTs: defining models, creating the plugin, setting up shadow tables, and performing your first sync between nodes.

## Installation

The `crdt` package is part of the root module:

```bash
go get github.com/xraph/grove@latest
go get github.com/xraph/grove/drivers/pgdriver@latest
```

## Define a CRDT-Enabled Model

Tag fields with `crdt:lww`, `crdt:counter`, or `crdt:set` to opt into CRDT behavior. Fields without CRDT tags are unaffected.

```go
package models

import "github.com/xraph/grove"

type Document struct {
    grove.BaseModel `grove:"table:documents,alias:d"`
    ID        string   `grove:"id,pk"`
    Title     string   `grove:"title,crdt:lww"`       // Last-Writer-Wins
    ViewCount int64    `grove:"view_count,crdt:counter"` // PN-Counter
    Tags      []string `grove:"tags,type:jsonb,crdt:set"`   // OR-Set
    Author    string   `grove:"author"`                // Normal field (no CRDT)
}
```

Each CRDT type has different merge behavior:

- `crdt:lww`: the write with the highest HLC timestamp wins. Best for scalar values like strings, booleans or JSON objects.
- `crdt:counter`: tracks per-node increments and decrements separately. Best for counters that several nodes update at once.
- `crdt:set`: an add-wins observed-remove set. Best for collections like tags or member lists.

## Create the CRDT Plugin

The plugin intercepts Grove mutations and tracks changes in shadow tables. It reads and writes those tables through a `crdt.Executor`, which you have to give it with `SetExecutor`. Grove doesn't ship one, but a Grove driver is close enough that the adapter is a few lines:

```go
import (
    "context"

    "github.com/xraph/grove/crdt"
    "github.com/xraph/grove/driver"
    "github.com/xraph/grove/hook"
)

// crdtExecutor adapts a Grove driver to crdt.Executor.
type crdtExecutor struct{ drv driver.Driver }

func (e crdtExecutor) ExecContext(ctx context.Context, query string, args ...any) (crdt.ExecResult, error) {
    return e.drv.Exec(ctx, query, args...)
}

func (e crdtExecutor) QueryContext(ctx context.Context, query string, args ...any) (crdt.Rows, error) {
    return e.drv.Query(ctx, query, args...)
}

// Create the plugin with a unique node identifier.
plugin := crdt.New(
    crdt.WithNodeID("node-1"),                 // required: unique per node
    crdt.WithTables("documents"),              // optional: restrict to specific tables
    crdt.WithTombstoneTTL(7 * 24 * time.Hour), // optional: tombstone expiry (default 7 days)
)
plugin.SetExecutor(crdtExecutor{drv: pgdb})   // pgdb is the opened *pgdriver.PgDB

// Add it to the Grove DB hook engine.
db.Hooks().AddHook(plugin, hook.Scope{
    Tables: []string{"documents"},
})
```

<Callout type="warn">
Without `SetExecutor`, nothing fails loudly: mutations simply record no CRDT state, and `Inspect` and the sync controller have no store to read from. The metadata store writes PostgreSQL-style `$1` placeholders, so the adapter above works as-is on PostgreSQL. For SQLite, rewrite `$n` to `?n` in the adapter.
</Callout>

The `NodeID` must be unique across all nodes in the sync cluster. Use descriptive names like `"cloud-us-east"`, `"edge-store-42"`, or `"browser-abc123"`.

## Shadow Tables

CRDT metadata is stored in shadow tables named `_<table>_crdt`. These sit alongside your primary table without modifying its schema.

### Option A: Ensure at Runtime

After `SetExecutor`, create the shadow table and its sync index:

```go
if err := plugin.EnsureShadowTable(ctx, "documents"); err != nil {
    log.Fatal(err)
}
```

### Option B: In Your Own Migration

There's no ready-made CRDT migration group. Put the DDL in a migration of your own with `crdt.ShadowTableDDL` and `crdt.ShadowTableSyncIndex`:

```go
var Migrations = migrate.NewGroup("crdt")

func init() {
    Migrations.MustRegister(&migrate.Migration{
        Name:    "create_documents_crdt",
        Version: "20260101000000",
        Up: func(ctx context.Context, exec migrate.Executor) error {
            if _, err := exec.Exec(ctx, crdt.ShadowTableDDL("documents")); err != nil {
                return err
            }
            _, err := exec.Exec(ctx, crdt.ShadowTableSyncIndex("documents"))
            return err
        },
        Down: func(ctx context.Context, exec migrate.Executor) error {
            _, err := exec.Exec(ctx, crdt.DropShadowTableDDL("documents"))
            return err
        },
    })
}
```

The shadow table has columns for the record key hash, field name, HLC timestamp and counter, node ID, a tombstone flag and the CRDT state (JSON), and the index covers the HLC columns for change queries.

## Perform Your First Sync

### Single Sync Round

```go
import "github.com/xraph/grove/crdt"

// Create a transport pointing at the remote node.
transport := crdt.HTTPTransport("https://cloud.example.com/sync")

// Create a syncer.
syncer := crdt.NewSyncer(plugin,
    crdt.WithTransport(transport),
    crdt.WithSyncTables("documents"),
)

// Run one sync round: pull remote changes, merge locally, push local changes.
report, err := syncer.Sync(ctx)
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Synced: %s\n", report) // pulled=5 pushed=3 merged=5 conflicts=0
```

### Background Sync Loop

For continuous sync, run the syncer in a background goroutine:

```go
// Sync every 30 seconds (configurable).
syncer := crdt.NewSyncer(plugin,
    crdt.WithTransport(transport),
    crdt.WithSyncTables("documents"),
    crdt.WithSyncInterval(30 * time.Second),
)

ctx, cancel := context.WithCancel(context.Background())
defer cancel()

// Run blocks until ctx is cancelled.
go syncer.Run(ctx)
```

### Real-Time Streaming

For lower latency, add SSE streaming alongside periodic sync:

```go
streamTransport := crdt.NewStreamingTransport(
    "https://cloud.example.com/sync",
    crdt.WithStreamTables("documents"),
    crdt.WithStreamReconnect(5 * time.Second),
)

syncer := crdt.NewSyncer(plugin,
    crdt.WithTransport(streamTransport),
    crdt.WithSyncTables("documents"),
    crdt.WithSyncInterval(30 * time.Second), // Fallback poll
)

go syncer.Run(ctx)        // periodic pull and push
go syncer.StreamSync(ctx) // SSE real-time changes
```

## Forge Integration

Inside a Forge app, the Grove extension mounts the sync routes, starts the syncer and manages the lifecycle. It doesn't set the plugin's executor or create shadow tables, so do both before you register it:

```go
import (
    "github.com/xraph/forge"
    "github.com/xraph/grove/drivers/pgdriver"
    groveext "github.com/xraph/grove/extension"
    "github.com/xraph/grove/crdt"
    "github.com/xraph/grove/hook"
)

pgdb := pgdriver.New()
if err := pgdb.Open(ctx, "postgres://user:pass@localhost:5432/mydb?sslmode=disable"); err != nil {
    log.Fatal(err)
}

plugin := crdt.New(crdt.WithNodeID("node-1"))
plugin.SetExecutor(crdtExecutor{drv: pgdb})
if err := plugin.EnsureShadowTable(ctx, "documents"); err != nil {
    log.Fatal(err)
}

syncer := crdt.NewSyncer(plugin,
    crdt.WithTransport(crdt.HTTPTransport("https://peer.example.com/sync")),
    crdt.WithSyncTables("documents"),
)

app := forge.New(forge.WithAppName("docs"))
err := app.RegisterExtension(groveext.New(
    groveext.WithDriver(pgdb),
    groveext.WithCRDT(plugin, hook.Scope{Tables: []string{"documents"}}),
    groveext.WithSyncer(syncer),
    groveext.WithSyncController(
        crdt.WithStreamPollInterval(2 * time.Second),
        crdt.WithStreamKeepAlive(30 * time.Second),
        crdt.WithPresenceEnabled(true),         // enable presence tracking
        crdt.WithPresenceTTL(30 * time.Second), // entry expiry (default 30s)
    ),
))
if err != nil {
    log.Fatal(err)
}
log.Fatal(app.Run())
```

This automatically registers sync and presence endpoints:

| Method | Path | Description |
|--------|------|-------------|
| POST | `/sync/pull` | Remote nodes pull changes |
| POST | `/sync/push` | Remote nodes push changes |
| GET | `/sync/stream` | SSE stream of real-time changes and presence events |
| GET | `/sync/ws` | WebSocket sync |
| POST | `/sync/presence` | Update or leave a presence topic |
| GET | `/sync/presence` | Get current presence snapshot for a topic |

Use `groveext.WithBasePath("/api/sync")` to change the route prefix.

## Inspecting State

For debugging, inspect the full CRDT state of any record:

```go
state, err := plugin.Inspect(ctx, "documents", "doc-1")
if err != nil {
    log.Fatal(err)
}

result := crdt.InspectState(state)
fmt.Println(result)
// Output:
// CRDT State for documents[doc-1]
//   title (lww): "Hello World" (node=node-1, hlc=HLC{ts:1234 c:0 node:node-1})
//   view_count (counter): 42 [node-1: +30 -0] [node-2: +12 -0]
//   tags (set): ["go", "crdt"]
```
