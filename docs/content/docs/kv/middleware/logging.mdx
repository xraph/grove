---
title: Logging Middleware
description: Structured logging for every KV operation with latency tracking.
---

The logging middleware records every KV operation with structured fields through a go-utils logger (`github.com/xraph/go-utils/log`), the same logger type Forge uses. Each log entry includes the operation type, key, and latency, making it straightforward to trace performance and debug issues.

## Installation

```go
import "github.com/xraph/grove/kv/middleware"
```

## Usage

```go
import (
    "github.com/xraph/go-utils/log"
    "github.com/xraph/grove/kv"
    "github.com/xraph/grove/kv/middleware"
)

store, err := kv.Open(drv,
    kv.WithHook(middleware.NewLogging(log.NewProductionLogger())),
)
```

### Constructor

```go
func NewLogging(logger log.Logger) *LoggingHook
```

| Parameter | Description |
|---|---|
| `logger` | A go-utils `log.Logger` |

## How It Works

The logging hook implements both `PreQueryHook` and `PostQueryHook`:

1. `BeforeQuery` records the start time in `qc.Values` under the key `_log_start`.
2. `AfterQuery` calculates the elapsed time and logs an `Info` entry with the message `kv command`.

### Log Fields

Each log entry includes:

| Field | Type | Description |
|---|---|---|
| `op` | `string` | Operation name (e.g., `"GET"`, `"SET"`, `"DEL"`) |
| `key` | `string` | The key being operated on |
| `latency` | `duration` | Time elapsed between BeforeQuery and AfterQuery |

The output format depends on the logger you pass. `log.NewProductionLogger()` writes JSON, `log.NewDevelopmentLogger()` writes readable console lines, and inside a Forge app you can pass the app's own logger.

## Middleware Ordering

Place the logging hook early in the middleware chain if you want to capture the total latency including all other middleware. Place it later if you want to measure only the time spent in the driver:

```go
// Logs total latency (including namespace prefixing, cache check, etc.)
store, err := kv.Open(drv,
    kv.WithHook(middleware.NewLogging(logger)),
    kv.WithHook(middleware.NewNamespace("tenant:acme")),
    kv.WithHook(middleware.NewCache(1000, 5*time.Minute)),
)
```

```go
// Logs only driver latency (excludes middleware overhead)
store, err := kv.Open(drv,
    kv.WithHook(middleware.NewNamespace("tenant:acme")),
    kv.WithHook(middleware.NewCache(1000, 5*time.Minute)),
    kv.WithHook(middleware.NewLogging(logger)),
)
```

## API Reference

| Method | Description |
|---|---|
| `NewLogging(logger)` | Create a new logging hook with the given `log.Logger` |
